Anatomical SVG fallback diagrams for the LeanHome Media target.

This directory hosts bundled high-contrast anatomical SVG illustrations shown
when a workout video is unavailable (offline + uncached). Per OpenSpec design.md
Decision 4 (Offline Fallback), the player falls back to vector illustration
of starting/ending positions with primary muscle group coloring.
